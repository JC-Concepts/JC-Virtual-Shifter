# Contributing

Bug reports, clear reproduction steps, and documentation corrections are welcome through [Issues](../../issues).

This repository does not accept source-code pull requests: firmware and desktop source are maintained in a separate private repository, and official binaries are produced there. Please do not open pull requests containing build scripts, protocol details, or source files.

Before filing an issue, check:

1. that you are using the latest [release](../../releases/latest),
2. the [troubleshooting guide](docs/troubleshooting.md),
3. the [wiring guide](docs/wiring.md) for your board's pin map.

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
