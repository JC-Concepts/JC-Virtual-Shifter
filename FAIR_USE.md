# Fair use and integrity

JC Virtual Shifter is intended to add virtual gears and physical shift controls to a normal indoor cycling setup.

Official firmware builds:

- forward measured trainer power without multiplying or synthesizing it,
- leave ERG target power under the riding app's control,
- apply the selected virtual gear to resistance and simulation commands.

Modified firmware, custom BLE peripherals, and other tools can present data that does not reflect real effort. Such setups are **not supported** by this project and may violate the rules of a riding platform, league, or event.

Competitive integrity ultimately depends on the riding platform and event organizers. This project publishes official, versioned builds so users have a known-good path; it does not claim that a general-purpose, user-flashable ESP32 can prove which firmware is running.

By using an official build you agree to use it only in ways permitted by the platforms and events you participate in.
