# Security policy

## Reporting a vulnerability

Please report security issues privately using the **Report a vulnerability** button on the [Security tab](../../security/advisories) of this repository.

Do not open a public issue for:

- credential or key exposure,
- a way to alter official release assets,
- issues with the web server or repository configuration,
- vulnerabilities in the desktop app or firmware.

Include the affected version, steps to reproduce, and any impact you believe is realistic. You should receive an acknowledgement within a few days.

## Supported versions

Only the latest published release receives security fixes.

## Scope note

This project runs on user-flashed ESP32 boards. Security reports about the official distribution pipeline are in scope. Reports that rely on a user voluntarily flashing unofficial firmware describe an expected limitation rather than a vulnerability in the official release; see [FAIR_USE.md](FAIR_USE.md).
